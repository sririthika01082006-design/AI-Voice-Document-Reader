🎤 AI-Powered Voice-Activated Document Reader

An AI-powered application that allows users to ask questions about PDF and TXT documents using voice commands and listen to answers.

🚀 Features

- 📄 Upload PDF and TXT documents
- 🎤 Ask questions using voice input
- 🗣️ Convert speech into text
- 🤖 Generate answers using NVIDIA AI
- 🔊 Read answers aloud using text-to-speech
- 💻 Simple and interactive Streamlit interface

🛠️ Technologies Used

- Python
- Streamlit
- NVIDIA LLM API
- Faster Whisper
- NumPy
- SoundDevice
- PyPDF
- pyttsx3

⚙️ How It Works

1. Upload a PDF or TXT document.
2. Ask a question using your voice.
3. The application converts speech into text.
4. NVIDIA AI generates an answer based on the document.
5. The answer is displayed and read aloud.

▶️ How to Run

1. Clone this repository.
2. Install the required Python packages.
3. Set your "NVIDIA_API_KEY" environment variable.
4. Run the application using Streamlit.

streamlit run nvidia3.py

🔐 Security

Keep your NVIDIA API key private. Never upload API keys or passwords to GitHub.
